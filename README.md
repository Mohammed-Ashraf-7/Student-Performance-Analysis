# Student Performance Analysis 📊

## 📌 Project Overview

This project analyzes student performance data to understand the factors that may affect students' final exam scores and academic performance.

The project was completed using **Python for data analysis and data preparation** and **Power BI for data visualization and dashboard development**.

## 🔍 Project Workflow

### 1. Data Analysis & Preparation – Python

Python was used to:

- Load and explore the dataset
- Check the data structure and data types
- Identify missing values
- Handle missing data
- Analyze categorical and numerical variables
- Calculate basic statistics
- Explore relationships between different factors and students' final scores

### 2. Data Visualization & Dashboard – Power BI

Power BI was used to create an interactive dashboard to analyze student performance.

The dashboard includes:

- Total Students
- Average Final Exam Score
- Average Previous Grade
- Average Attendance
- Pass Rate
- Internet Access Rate
- Part-Time Job Rate
- Final Grade Distribution
- Average Score by Gender
- Average Score by Parental Education
- Study Hours vs Final Score
- Attendance vs Final Score
- Previous Grade vs Final Score

## 📈 Key Analysis Areas

The project focuses on studying the relationship between students' academic performance and factors such as:

- Study Time
- Attendance
- Previous Grades
- Gender
- Parental Education
- Internet Access
- Extracurricular Activities
- Part-Time Jobs
- Sleep Hours

## 📊 Dashboard

The Power BI dashboard provides an interactive view of student performance and allows users to explore different factors using filters and visualizations.

## 🎯 Project Goal

The main goal of this project is to identify patterns and relationships in student performance and understand which factors are associated with higher or lower final exam scores.
